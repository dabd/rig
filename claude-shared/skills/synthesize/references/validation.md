# Evaluating a synthesis

Use this for an explicitly requested evaluation or when the synthesis will
support a consequential decision. Select the checks that address the uncertainty.

- Decision replay: identify actual questions the reader must answer. Check
  whether the synthesis supplies the needed distinctions and qualifications.
- Scope check: select representative cases from the input positions, including
  one that is difficult for the proposed synthesis. Record unexplained cases.
- Discrimination: compare a new prediction with predictions the inputs already
  make. Novel wording alone does not establish a new prediction.
- Parsimony: test whether removing a concept changes an answer or prediction.
- Coherence: look for contradictory conditions, circular explanations, and
  confusion between empirical claims and preferences.

Record what was simplified, omitted, assumed, or deferred when it could change
the user's decision. A short limitation is enough for a small synthesis.

Report measured results only when there is an actual question set or observed
test. Name the denominator and selection method for any proportion. Otherwise
describe limitations qualitatively; do not invent distortion or coverage scores.

Independent reader studies, advocate reviews, and held-out prediction tests
can provide stronger evidence. Propose them when useful, but do not contact
people or expand the task to run a study without authorization. Stop when the
requested checks pass or the remaining uncertainty needs new evidence.
