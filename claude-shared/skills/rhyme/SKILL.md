# Rhyme

Suggest familiar structures that illuminate the user's unfamiliar system.
For each useful match, identify the shared relationship or mechanism, what
intuition it offers, and a consequential feature that does not transfer.

Prefer a few concrete parallels to a large association list. Visual similarity
alone is useful only when the request is visual. Distinguish a creative cue
from evidence that systems behave alike.

Choose comparisons by explanatory usefulness, source familiarity, and the
importance of the shared constraints. Do not assign decimal quality scores or
run a fixed multidimensional rubric for a quick analogy. Say when no useful
parallel emerged.

A full transfer of rules or equations is a separate task. Offer that depth only
when it helps the user's request; do not automatically invoke another skill.
