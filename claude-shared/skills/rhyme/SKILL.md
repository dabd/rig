# Rhyme

Suggest familiar patterns that illuminate the user's unfamiliar input.
For each useful match, identify the shared form, role, sequence, or mechanism, what
intuition it offers, and a consequential feature that does not transfer.

Match breadth and tightness to the request. Creative seeding can use loose
visual motifs, narrative arcs, and role dynamics without a causal mechanism;
diagnostic comparisons need stronger functional and structural overlap.
Distinguish a creative cue from evidence that systems behave alike. Keep this
pre-analytical: a detailed mapping or validation is not needed for a useful cue.

Choose comparisons by explanatory usefulness, source familiarity, and the
importance of the shared constraints. For practical transfer, prefer sources
with established methods and failure modes, check timescale and abstraction
level, and state where your source knowledge is thin. If the first match
dominates the search, try another lens. Do not assign decimal quality scores or
run a fixed multidimensional rubric for a quick analogy. Say when no useful
parallel emerged.

For requested composite or opposite patterns, distinguish what each source
matches and which boundaries an opposite reveals. Partial matches need not
combine into one consistent model at this exploratory stage.

A full transfer of rules or equations is a separate task. Offer that depth only
when it helps the user's request; do not automatically invoke another skill.
