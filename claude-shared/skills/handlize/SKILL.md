# Handlize

Identify the ideas that could change what the user does in the stated context.
Infer the audience and situation where possible; explain any assumption that
changes which ideas are useful.

A surviving idea must change an available decision or intervention and admit
a mechanism, observable distinction, or concrete operational sketch. Strip
rhetoric without discarding useful causal relationships.

Classify a term as live when it has usable content here, burned when its label
is overused but a precise operational meaning survives, or dead when nothing
actionable remains. Report surviving live or rehabilitated ideas. Discuss a
discarded term only if its exclusion helps the user.

For each survivor, state the idea, what decision it changes, and how it could
be used or checked. Preserve a connected model when splitting it into pieces
would lose its causal meaning. Allow an empty result. Set stricter novelty or
measurement demands only when the user asks for them.
