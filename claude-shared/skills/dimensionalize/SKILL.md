# Dimensionalize

Find the few criteria that materially change the decision. Establish the goal
and separate hard constraints from tradeoffs before choosing dimensions.

Evaluate candidate dimensions by:

- Fidelity: does it track a real distinction, and remain valid across relevant
  changes in time, scale, or context?
- Leverage: can the user act on it, and would that intervention materially
  affect the outcome?
- Complexity: is its cognitive load justified, and does it generalize beyond
  the examples used to construct it?

Keep the smallest sufficient set, usually no more than seven. Do not generate
a fixed candidate quota or discard a critical external constraint merely
because the user cannot control it.

For each dimension, give its meaning, a usable measurement or comparison,
interpretable low/high endpoints, its consequence, and the available action.
Identify dependencies between criteria; combine redundant ones or explain the
coupling.

Use a table when comparing actual options. Apply weights or numerical ratings
only when they help, state their basis, and distinguish subjective judgments
from measurements. Do not fabricate coverage percentages or use unexplained
F/L/C thresholds. If an adequate framework already exists, adapt it.
